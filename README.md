# Figma Mini – Foundation Version 🎨

A **mini Figma-like design tool** built using **Vanilla JavaScript**, **HTML**, and **CSS**.  
This project demonstrates core canvas interactions such as **drag, resize, rotate**, along with a **properties panel**, **keyboard controls**, **auto-save**, and **JSON export**.

---

## ✨ Features

- ➕ Add **Rectangle** and **Text** elements  
- 🎯 Select / Deselect elements  
- 🖱️ Drag elements inside canvas (with boundary limits)  
- 📐 Resize elements using **4 corner handles**  
- 🔄 Rotate elements using a rotate handle  
- 🎛️ Properties Panel:
  - Width
  - Height
  - Background Color
  - Text editing (for text elements only)
- ⌨️ Keyboard Controls:
  - Arrow keys to move
  - Delete key to remove element
- 💾 Auto-save layout using **localStorage**
- 🔁 Load saved layout on page refresh
- 📤 Export canvas layout as **JSON**
